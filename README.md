# NetScan

Un scanner de ports ultra-rapide codé en Python utilisant le multi-threading pour mapper une cible rapidement.

### Features
- **Multi-threading** : Scan 100 ports en simultané pour une vitesse max.
- **Banner Grabbing** : Tente de récupérer la version du service qui tourne sur le port.
- **Interface Clean** : Des tableaux propres grâce à Rich.
